## 4. 决策项（已裁决，实现遵照）

| ID | 决策 | 理由 |
|---|---|---|
| D-01 | 存档用自定义 JSON（字段语义对照原版），不承诺读原版二进制存档 | 原版 Gson 字段+混淆复杂度高、收益低；语义对照保底 |
| D-02 | 原版漏存的 RNG counter（ai/shuffle/card_random/monster_hp 的部分）在自研存档中**全部保存** | 可复现优先于兼容 |
| D-03 | 原版不可回放随机：若只影响表现 → 忽略；若影响状态 → 改接入种子 RNG 并在模块记录中标注差异清单 | 忠实 vs 可验证的取舍 |
| D-04 | 数值哨兵 -1/-2 用显式枚举建模，但存档/显示层保持原语义 | 防 i32 误算 |
| D-05 | 动作时长 → 即时完成（队列屏障语义保留），FAST/慢速档不移植时长 | 文字 UI 无动画；顺序不变 |
| D-06 | 本地化首版仅英文 + 中文卡名/关键词可选；文本 key 与原版一致 | 控制灌注工作量 |
| D-07 | 平台目标：windows-x86_64 与 macOS（x86_64 + aarch64 兼容设计）；见 docs/08 | 用户要求 |
| D-08 | 网络功能（上传/排行榜/Steam）不实现；成就本地记录 | 独立运行 |
