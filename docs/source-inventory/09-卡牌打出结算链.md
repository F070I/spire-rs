# 盘点原始记录 09：卡牌打出结算链 / 牌堆操作 / 战斗生命周期

> 路径均相对 `src/main/java/com/megacrit/cardcrawl/`。阶段 0 原始盘点记录。

## 0. 驱动模型总览（理解一切的前提）

- **GameActionManager** 是唯一的调度核心。四条队列按固定优先级消费：
  1. `actions`（普通动作队列，addToTop=插入 index 0，addToBottom=追加尾部）
  2. `preTurnActions`（addToTurnStart，回合开始动作）
  3. `cardQueue`（CardQueueItem 卡牌打出队列）
  4. `monsterQueue` + `monsterAttacksQueued` 标志 + `turnHasEnded` 标志
- `update()`：每帧只调 currentAction.update() 一次；currentAction 结束后取下一个；全部队列空且非 usingCard → 回 WAITING_ON_USER 并 hasControl=false。
- **每帧每 action 只 update 一次**；tickDuration() = duration -= deltaTime，<0 则 isDone。多帧动作靠 `duration == 初始值` / firstFrame / shuffleCheck 等"首帧判定"。
- `addToBottom/addToTop/addToTurnStart` **只在 room.phase == COMBAT 时入队，否则静默丢弃**——重大移植陷阱。

## 1. 打出一张卡的完整时序表

### 阶段 A：玩家输入入队（无钩子）
- clickAndDragCards()：在投放区判定 hasEnoughEnergy() && canUse(this, null) → playCard()；不满足 → ThoughtBubble(cantUseMessage) + releaseCard()。
- playCard()（L1387-1404）：`!queueContains(card)`（用 == 比较）→ `actionManager.cardQueue.add(new CardQueueItem(hoveredCard, hoveredMonster))`。CardQueueItem 构造器把 energyOnUse 设为 EnergyPanel.getCurrentEnergy()。**入队瞬间不扣能量、不离手**。

### 阶段 B：GameActionManager.getNextAction() 消费 cardQueue
依次：
1. `usingCard = true`；队头 card == null → callEndOfTurnActions()。
2. `c.isInAutoplay = item.autoplayCard`；item.randomTarget → getRandomMonster(null, true, cardRandomRng) 重定目标。
3. 判定 `canPlayCard = c.canUse(player, monster) || c.dontTriggerOnUseCard`。
4. **canUse 通过时，onPlayCard 钩子链**（受 !card.dontTriggerOnUseCard 保护，L274-307），确切顺序：
   1. **玩家 powers** onPlayCard(card, monster)
   2. **每只怪的 powers**（按 monsters.monsters 顺序）
   3. **玩家 relics** onPlayCard
   4. **stance** stance.onPlayCard(card)
   5. **blights** onPlayCard
   6. **手牌** 每张 card.onPlayCard（含被出卡自身，此时还在手牌！）
   7. **弃牌堆** 每张
   8. **抽牌堆** 每张
5. 计数：player.cardsPlayedThisTurn++、cardsPlayedThisTurn/ThisCombat.add(card)；INFINITY(25)/NINJA(10 Shiv) 成就。
6. 目标失效分支（L339-358）：card.target == ENEMY && (monster == null || monster.isDeadOrEscaped()) → 卡从 limbo 淡出，**不调用 useCard**。
7. 否则 → **player.useCard(card, monster, item.energyOnUse)**。
8. `cardQueue.remove(0)`。
9. 若 !canPlayCard && c.isInAutoplay → c.dontTriggerOnUseCard = true; addToBottom(new UseCardAction(c))。
10. 不可用分支：limbo 中 fadingOut + ExhaustCardEffect，弹 ThoughtBubble(cantUseMessage)。

### 阶段 C：AbstractPlayer.useCard(c, monster, energyOnUse)（L1472-1498）
1. ATTACK → useFastAttackAnimation()。
2. `c.calculateCardDamage(monster)`（对目标重新计算卡面数值）。
3. X 费（cost==-1）：若 EnergyPanel.totalCount < energyOnUse && !c.ignoreEnergyOnUse → c.energyOnUse = EnergyPanel.totalCount；若 cost==-1 && isInAutoplay → freeToPlayOnce = true。
4. **`c.use(this, monster)`** —— 卡牌效果本体：所有子 action 在此入队。
5. `addToBottom(new UseCardAction(c, monster))` —— **构造器立即执行副作用**。
6. !c.dontTriggerOnUseCard → **hand.triggerOnOtherCardPlayed(c)**（CardGroup.java L1111-1119：手牌每张 c != usedCard 才触发 triggerOnOtherCardPlayed，随后**玩家所有 powers** onAfterCardPlayed）。
7. `hand.removeCard(c)`（纯 group.remove，无钩子）。
8. cardInUse = c。
9. 扣费：`costForTurn > 0 && !freeToPlay() && !isInAutoplay && !(hasPower("Corruption") && type == SKILL)` → energy.use(costForTurn)。
10. !hand.canUseAnyCard() && !endTurnQueued → 结束回合按钮发光。

### 总钩子顺序一览（一张普通卡从出列到弃牌）
`canUse` → powers/relics/stance/blights/cards 的 `onPlayCard` → `calculateCardDamage` → `card.use()`（卡内 action 入队）→ UseCardAction 构造器：玩家 powers onUseCard → 玩家 relics onUseCard → 手牌/弃牌堆/抽牌堆 triggerOnCardPlayed → 怪物 powers onUseCard → hand.triggerOnOtherCardPlayed（手牌 → 玩家 powers onAfterCardPlayed）→ 出手牌/扣费 → UseCardAction.update 首帧：玩家 powers onAfterUseCard → 怪物 powers onAfterUseCard → 标志重置 → moveToDiscardPile/moveToExhaustPile/moveToDeck/moveToHand → addToBot(HandCheckAction)。

## 2. UseCardAction 完整逻辑（actions/utility/UseCardAction.java）

### 构造器（副作用在 useCard 里 addToBottom 时同步发生）
- `exhaustCard = card.exhaustOnUseOnce || card.exhaust`；duration = 0.15F；setValues(player, null, 1)。
- 钩子链（均受 !card.dontTriggerOnUseCard 保护）：
  1. 玩家 powers onUseCard(card, this)（L35-39）
  2. 玩家 relics onUseCard(card, this)（L41-45）
  3. **手牌** triggerOnCardPlayed(card)（L48-52）
  4. **弃牌堆** triggerOnCardPlayed(card)（L53-57）
  5. **抽牌堆** triggerOnCardPlayed(card)（L58-62）
  6. **每只怪的 powers** onUseCard(card, this)（L65-71）
- actionType = exhaustCard ? EXHAUST : USE。

### update()（duration == 0.15F 首帧完成全部结算，之后 tickDuration）
1. 玩家 powers onAfterUseCard(card, this) → 怪物 powers onAfterUseCard。
2. `freeToPlayOnce = false; isInAutoplay = false`。
3. **purgeOnUse 分支**（L103-108）：addToTop(ShowCardAndPoofAction)；cardInUse = null；return。卡对象被彻底废弃。
4. **POWER 分支**（L111-124）：addToTop(ShowCardAction) + WaitAction(0.7/0.1)；hand.empower(card)（souls.empower，**POWER 卡不入任何牌堆，对象成为孤儿**）；hand.applyPowers(); glowCheck(); cardInUse = null；return。
5. **普通分支**（L124-152）：
   - Strange Spoon：exhaustCard && hasRelic("Strange Spoon") && type != POWER → spoonProc = cardRandomRng.randomBoolean()（50%）。
   - !exhaustCard || spoonProc：reboundCard → moveToDeck(card, false)（置顶）；shuffleBackIntoDrawPile → moveToDeck(card, true)（随机位）；returnToHand → moveToHand(card) + player.onCardDrawOrDiscard()；否则 → **moveToDiscardPile(card)**。
   - 真消耗 → **moveToExhaustPile(card)** + checkForPactAchievement()。
   - exhaustOnUseOnce = false; dontTriggerOnUseCard = false。
   - addToBot(new HandCheckAction())。

## 4. DrawCardAction 逐帧行为（actions/common/DrawCardAction.java）

- 构造器（L29-73）：endTurnDraw=true 时加 PlayerTurnEffect；`actionType=DRAW`；变体 `(amount, clearDrawHistory)` 控制**静态共享列表 drawnCards 是否首轮清空**；`(amount, followUpAction, clearDrawHistory)` 携带后继动作。
- update() 每帧（L76-162），任何一帧的顺序：
  1. clearDrawHistory → 清 drawnCards（静态！）。
  2. hasPower("No Draw") → power.flash() → endActionWithFollowUp()。
  3. amount <= 0 → end。
  4. 记录 deckSize/discardSize；**SoulGroup.isActive()（有灵魂在飞）→ 直接 return**：不 tick duration（防抽到飞行中的卡）。
  5. deckSize + discardSize == 0 → end。
  6. hand.size() == 10 → createHandIsFullDialog() → **end（本次抽牌剩余量整体丢弃）**。
  7. **shuffleCheck（仅一次）**：
     - amount + hand.size() > 10 → amount = 10 - hand.size()（削减）+ 手满提示。
     - amount > deckSize → **洗牌分解**：addToTop(DrawCardAction(超出量 tmp, followUpAction, false))；addToTop(EmptyDeckShuffleAction())；deckSize != 0 时 addToTop(DrawCardAction(deckSize, false))；amount = 0; isDone。执行顺序：先抽 deckSize 张 → 洗牌 → 再抽超出部分。
  8. duration -= dt；duration < 0 时：重置 duration，amount--；drawPile 非空 → drawnCards.add(top)、**player.draw()**（无参版）、refreshHandLayout()；amount == 0 → endActionWithFollowUp。
- **每帧抽 1 张**。
- **无参 player.draw()**（L1814-1822）：hand.size()==10 → 手满提示并 return（丢掉这 1 张）；播放音效 → draw(1) → onCardDrawOrDiscard()。
- **player.draw(int)**（L1785-1812）单张顺序：取 drawPile.getTopCard() → 设入场坐标 → **c.triggerWhenDrawn()** → hand.addToHand(c) → drawPile.removeTopCard() → **玩家 powers onCardDraw(c)** → **relics onCardDraw(c)**。注意 triggerWhenDrawn 在卡进手牌**之前**，onCardDraw 在进手牌**之后**。
- **EmptyDeckShuffleException：本反编译源码中不存在**（全库 grep 零命中）。desktop-1.0 用显式分解（EmptyDeckShuffleAction + 两段 DrawCardAction），不是异常控制流。
- `EmptyDeckShuffleAction`：**构造器**触发 relics onShuffle()（只有 relics，无 powers！L43-45）；update 第一帧 discardPile.shuffle(shuffleRng)；之后每帧逐张飞回抽牌堆。
- `ShuffleAction`：triggerRelics 时先 relics onShuffle()，再 group.shuffle()。

## 5. 弃牌链

### DiscardAction（actions/common/DiscardAction.java）
- update 首帧（L44-91）：
  - 怪全死 → isDone。
  - `hand.size() <= amount` → **弃全部**：循环 getTopCard() → moveToDiscardPile(c)；!endTurn 时 c.triggerOnManualDiscard()；每张 GameActionManager.incrementDiscard(endTurn)；然后 hand.applyPowers()。
  - `isRandom` → 循环 amount 次：hand.getRandomCard(**cardRandomRng**) → moveToDiscardPile + triggerOnManualDiscard + incrementDiscard。
  - 非随机：amount < 0 → handCardSelectScreen.open(TEXT[0], 99, true, true)（任意张）；否则 numDiscarded = amount，open(TEXT[0], amount, false)（必须选满）。
- 后续帧：对 selectedCards 逐张 moveToDiscardPile + triggerOnManualDiscard + incrementDiscard。

### incrementDiscard（GameActionManager L565-574，static）
totalDiscardedThisTurn++；**仅当 !turnHasEnded && !endOfTurn** → player.updateCardsOnDiscard()（手/弃/抽全部卡 didDiscard()）→ relics onManualDiscard()。即回合末弃牌不触发手动弃牌钩子。

### DiscardAtEndOfTurnAction（actions/common/DiscardAtEndOfTurnAction.java）
update 首帧（L29-64）：
1. 手牌遍历：e.retain || e.selfRetain → **移入 player.limbo**（addToTop）并从手牌删除。
2. addToTop(RestoreRetainedCardsAction(limbo))。
3. 无 Runic Pyramid 且无 Equilibrium power → 循环 tempSize 次 addToTop(DiscardAction(player, null, hand.size(), true, true))——每份进入时 hand.size() <= amount → 弃全部。
4. 手牌 clone + `Collections.shuffle(cards)`（**无种子 java.util.Random**）→ 每张 triggerOnEndOfPlayerTurn()；基类实现（AbstractCard.java L2380-2384）：**isEthereal → addToTop(ExhaustSpecificCardAction(this, hand))**。
5. isDone。

### RestoreRetainedCardsAction（actions/unique/）
对传入组（limbo）迭代：retain || selfRetain → **e.onRetained()** → hand.addToTop(e) → retain = false → 移除；最后 refreshHandLayout()。

### 回合末弃牌的入队点
`AbstractRoom.endTurn()`（L419-454）：player.applyEndOfTurnTriggers() → addToBottom(ClearCardQueueAction) → addToBottom(DiscardAtEndOfTurnAction) → 三个牌堆 + 悬停卡 resetAttributes() → 匿名 action（addToBot(EndTurnAction) + WaitAction(1.2) + !skipMonsterTurn 时 addToBot(MonsterStartTurnAction)；monsterAttacksQueued = false）→ isEndingTurn = false。

## 7. DamageAction / DamageAllEnemiesAction

### DamageAction（actions/common/DamageAction.java）
- 构造器：setValues(target, info)（amount = info.output, source=info.owner）后覆盖 duration = 0.1F；变体支持 superFast(skipFast)、muteSfx、stealGoldAmount。
- update（L62-102）：
  1. `shouldCancelAction() && info.type != THORNS` → isDone（**THORNS 豁免取消判定**）。
  2. 首帧：非 THORNS 且 info.owner.isDying || halfDead → isDone；FlashAtkImgEffect；goldAmount != 0 → stealGold()：target.gold==0 直接返回；goldAmount = min(gold, goldAmount)；扣金。
  3. tickDuration()。
  4. **isDone 后才结算伤害**（两段式）：tint → **target.damage(info)** → areMonstersBasicallyDead() → clearPostCombatActions() → !skipWait && !FAST_MODE → addToTop(WaitAction(0.1))。

### DamageAllEnemiesAction
- 两种构造：传 `int[] damage`（调用方用 DamageInfo.createDamageMatrix(base) 预计算，cards/DamageInfo.java L177-184）或传 baseDamage（utilizeBaseDamage=true，**首帧才** createDamageMatrix）。
- 首帧：对每个活怪加 FlashAtkImgEffect。
- isDone 后：
  1. **玩家 powers 每个调 onDamageAllEnemies(this.damage)**（可修改矩阵）。
  2. 按索引遍历怪：!isDeadOrEscaped() → m.damage(new DamageInfo(source, damage[i], damageType))（死怪跳过但数组不重排）。
  3. basically dead → clearPostCombatActions；WaitAction(0.1)。

## 8. ApplyPowerAction（actions/common/ApplyPowerAction.java）

### 构造器副作用（L56-110）
1. Snake Skull：source 玩家、target≠source、Power=="Poison" → powerToApply.amount++（直接改被施加的能力对象）。
2. **Corruption 卡费联动**：手牌/抽牌堆/弃牌堆/消耗堆全部 SKILL modifyCostForCombat(-9)。
3. 怪全死 → duration = 0; isDone（构造即完成）。

### update()（L143-315）
1. target == null || target.isDeadOrEscaped() → isDone。
2. 首帧：
   - **NoDrawPower 特判**：powerToApply 是 NoDrawPower 且 target 已有同 ID → isDone。
   - source != null → source 的 powers 逐个 **onApplyPower(powerToApply, target, source)**。
   - Champion Belt：source 玩家、target≠source、ID=="Vulnerable"、target 无 Artifact → relic onTrigger(target)。
   - target 是怪且已死/逃 → isDone。
   - **Ginger**（Weakened 对玩家）/**Turnip**（Frail 对玩家）：flash + TextAboveCreatureAction + **duration -= deltaTime 后直接 return**——本次施加被无声取消。
   - **Artifact 拦截**：target.hasPower("Artifact") && powerToApply.type == DEBUFF → TextAboveCreatureAction + NULLIFY_SFX + Artifact.flashWithoutSound() + onSpecificTrigger()（消耗一层）+ return。**能力未被施加**。
   - FlashAtkImgEffect。
   - **已有同 ID power**（排除 "Night Terror"）→ p.stackPower(amount) + p.flash() + 浮字 + p.updateDescription()。
   - **新增**：target.powers.add(powerToApply) → **Collections.sort(target.powers)** → powerToApply.onInitialApplication() + flash → onModifyPower()；玩家 BUFF 数 ≥10 → POWERFUL 成就。
3. tickDuration。

## 9. 战斗开始 / 回合流转 / 战斗结束

### 战斗开始完整序列

   - 重置计数（damagedThisCombat、cardsPlayedThisTurn、maxOrbs=0）、orbs.clear() + increaseMaxOrbSlots(masterMaxOrbs)、isBloodied、gameHandSize = masterHandSize、cardInUse = null。
   - **drawPile.initializeDeck(masterDeck)**。

   - SlaversCollar.beforeEnergyPrep → **energy.prep()**。
   - **powers.clear()**（战斗残留能力的唯一清理点）。

## 10. Soul / SoulGroup（cards/Soul.java、cards/SoulGroup.java）

- SoulGroup：AbstractRoom.souls，预创建 20 个 Soul 的池。**DrawCardAction 每帧检查 SoulGroup.isActive()，有灵魂飞行时暂停抽牌**。
- Soul 五种投递（每次都做两件事：**立即修改数据** + 启动飞行动画）：
  | 方法 | 数据落点 | 动画 |
  |---|---|---|
  | discard(card) | player.discardPile.addToTop(card) | 手中→弃牌堆 |
  | shuffle(card, invisible) | drawPile.addToTop(card) | 弃牌堆→抽牌堆 |
  | onToDeck(card, randomSpot) | addToRandomSpot（cardRandomRng）或 addToTop | 当前位→抽牌堆 |
  | onToBottomOfDeck(card) | drawPile.addToBottom(card) | 当前位→抽牌堆 |
  | obtain(card) | masterDeck.addToTop(card)（Hoarder mod ×3） | 当前位→牌库 |
  | empower(card) | **group = null（不入任何堆）** | 卡飞向玩家（POWER 卡） |
- **语义要点**：卡的归属在 moveTo* 调用瞬间就已确定（Soul 构造时落组），飞行动画纯表现层；但它通过 SoulGroup.isActive() 反向节流抽牌。

## 11. Rust 移植风险点清单

1. **异常控制流不存在**：EmptyDeckShuffleException 全库零命中——按显式分解实现。
2. **帧驱动 + 每帧一 action**：Rust 需引入"逻辑帧"概念：可按固定 dt 或"立即推进直到等待"状态机。多帧行为：DrawCardAction 每帧抽 1 张、EmptyDeckShuffleAction 每帧飞 1 张、Soul 动画逐帧。
3. **"首帧判定"脆弱性**：duration == 0.15F（浮点相等比较初始值！）等 → Rust 改为显式 phase 枚举。
4. **构造器副作用 + 入队时序**：钩子在构造时触发，而构造发生在上游 card.use() 里——早于队列中排在前面的大量 action 执行 → 把"钩子触发"与"action 执行"分成构造/执行两个阶段并保留此顺序。
5. **addToTop/addToBottom 的静默丢弃**：仅 COMBAT 时生效。
6. **双重队列交互**：actions 与 cardQueue 交错；removeFromQueue 可中途撤销 cardQueue 项；limbo 组承担"排队中的卡"的暂存。
7. **全局单例与静态可变状态**：DrawCardAction.drawnCards 静态、GameActionManager 静态计数、AbstractRoom.waitTimer/blizzardPotionMod（static!）。
8. **RNG 语义分散**：洗牌 = shuffleRng；卡牌随机 = cardRng；战斗中随机弃牌/randomSpot = cardRandomRng；奖励金 = treasureRng/miscRng；药水 = potionRng；Strange Spoon 用 cardRandomRng；getRandomCard(useRng=false)、DiscardAtEndOfTurn 的洗牌、Many 布局用非种子随机（不可回放）——移植时需决定是否改为种子 RNG。
9. **卡牌对象身份 vs equals**：queueContains 用 ==，removeFromQueue 用 equals → Rust 用唯一 id（uuid）替代指针比较。
10. **钩子相对顺序不可变**：onPlayCard: powers→relics；UseCardAction 构造：powers→relics→cards；onExhaust: **relics→powers→card**；onCardDraw: powers→relics；onDrawOrDiscard: powers→relics。逐点核对，不能统一。
11. **迭代中修改集合**：UseCardAction 构造器遍历三个组时卡钩子可能改组；DiscardAtEndOfTurnAction 用迭代器 remove → 快照或事件队列。
12. **两段式伤害**：DamageAction 伤害在动画结束帧才 target.damage；DamageAllEnemiesAction 先 onDamageAllEnemies 后逐个结算且矩阵按怪索引不重排。THORNS 绕过 shouldCancelAction 与 owner 死亡检查。
13. **ApplyPowerAction 的 duration-=dt 拦截 hack**（Ginger/Turnip/Artifact）与 NoDrawPower 不叠加特判、Corruption 四堆费用联动——逐条保留。
14. **标志位生命周期**：freeToPlayOnce/isInAutoplay/dontTriggerOnUseCard/exhaustOnUseOnce/returnToHand/reboundCard/shuffleBackIntoDrawPile/purgeOnUse 在 getNextAction 与 UseCardAction.update 两处设置/重置。
