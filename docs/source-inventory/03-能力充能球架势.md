## 2. 力量叠加规则

**ApplyPowerAction.update() 完整流程**（actions/common/ApplyPowerAction.java）：
1. `NoDrawPower` 已存在则直接放弃（L147）。
2. **施加者** `source.powers` 依次 `onApplyPower(powerToApply, target, source)`（L157）。
3. 免疫检查：`Ginger` 挡 Weak、`Turnip` 挡 Frail（玩家持有遗物）、`Artifact` 挡 DEBUFF——命中时对 Artifact 调 `onSpecificTrigger()` 并中止（L199-208）。Champion Belt/Snake Skull 在此修改。
4. 已有同 ID（除 "Night Terror"）：`p.stackPower(amount)` → `p.flash()` → `p.updateDescription()`（L216-258）。**不走 onInitialApplication，不排序。**
5. 新增：`powers.add` → **`Collections.sort(powers)`**（L267）→ `onInitialApplication()` → flash（L266-272）。

**构造器副作用**：Snake Skull（source 玩家、target≠source、Poison）→ `powerToApply.amount++`；**Corruption**：手牌/抽/弃/消耗堆全部 SKILL `modifyCostForCombat(-9)`；怪全死 → 构造即 isDone。

**特殊叠加行为**：
- Strength/Dexterity/Focus/GainStrength：`amount==0` 时 `addToTop(RemoveSpecificPowerAction)`；构造与叠加钳 ±999；`canGoNegative=true`；updateDescription 按正负切换 BUFF/DEBUFF。
- FocusPower：`amount>=25` 解锁成就。
- PlatedArmorPower：wasHPLost 中受击掉 1 层；`onRemove` 触发怪物 ChangeStateAction("ARMOR_BREAK")；`atEndOfTurnPreEndTurnCards` 按 amount 获得格挡。
- TimeWarpPower：onAfterUseCard 计数，`amount==12` 清零 + `callEndTurnEarlySequence()` 强制结束玩家回合 + 全体怪 +2 力。
- TimeMazePower：onAfterUseCard 倒数，归零重置 15 并清 cardQueue/limbo、禁结束按钮。
- MantraPower（watcher）：stackPower 中 `amount>=10` → ChangeStanceAction("Divinity")，amount-=10。
- PanachePower：amount 固定计数器 5，damage 单独存字段。
- TheBombPower：构造时 `ID = "TheBomb" + bombIdOffset++`（静态计数器允许多实例）。
- MalleablePower：amount 与 basePower 双字段。
- DrawPower：构造时直接改 `gameHandSize += amount`，onRemove 还原。
- DrawReductionPower：onInitialApplication 时 `gameHandSize--`，onRemove `++`。
- **justApplied 模式**（Vulnerable/Weak/Frail/NoBlock/AttackBurn/SkillBurn/DoubleDamage/DrawReduction/Intangible）：怪物施加的回合型减益在 atEndOfRound 第一次触发时跳过递减。
- InvinciblePower：onAttackedToChangeDamage 压伤害到剩余额度并扣 amount，atStartOfTurn 重置。
- ReducePowerAction（L58-66）：`this.amount < reduceMe.amount` 才真正减，否则 `addToTop(RemoveSpecificPowerAction)`。

## 3. priority 字段

- `priority = 5` 默认；`compareTo` = priority 升序。
- **排序生效点只有两处**：ApplyPowerAction.java:267 与 ApplyPoisonOnRandomMonsterAction.java:155。每次"首次施加"整体重排；之后所有钩子遍历按此顺序。`addPower` 直接加入的不排序。
- 设置了 priority 的能力：Confusion=0、DoubleDamage=6、PenNib=6、Frail=10、DrawCardNextTurn=20、ToolsOfTheTrade=25、Establishment=25、Flight=50、Reactive=50、Intangible=75、IntangiblePlayer=75、Weak=99、Invincible=99、Constricted=105。
- Collections.sort 稳定，同 priority 保持插入序。

## 4. 伤害修正链（完整顺序）

### (a) `cards/DamageInfo.applyPowers(owner, target)`（L29-133）— 怪物 intent 与 createDamageMatrix 用
- owner 非玩家（怪物攻击，L36-88）：
  1. Endless 模式 `DeadlyEnemies` 疫病乘算；
  2. `owner.powers` 依次 `atDamageGive`；
  3. `target.powers`（玩家）`atDamageReceive`；
  4. `player.stance.atDamageReceive`（Wrath ×2）；
  5. `owner.powers` `atDamageFinalGive`；
  6. `target.powers` `atDamageFinalReceive`；
  7. `output = MathUtils.floor(tmp)`，<0 钳 0；每步若 `base != (int)tmp` 则 isModified=true。
- owner 为玩家（L93-133）：owner powers `atDamageGive` → **`player.stance.atDamageGive`**（Wrath/Divinity ×2/×3）→ target powers `atDamageReceive` → owner powers `atDamageFinalGive` → target powers `atDamageFinalReceive` → floor 钳 0。**此路径不含遗物钩子。**
- `applyEnemyPowersOnly(target)`（L143）：只跑 target 的 receive 两段。
- THORNS 类型普遍跳过 applyPowers（isPureDamage 矩阵不修正）。

### (b) `AbstractCard.calculateCardDamage(mo)` / `applyPowers()` — 玩家卡牌
1. `player.relics` `atDamageModify(tmp, this)`；
2. `player.powers` `atDamageGive(tmp, damageTypeForTurn, this)`（力量加法）；
3. `player.stance.atDamageGive`（**架势倍率位于力量之后、易伤之前**）；
4. target(monster).powers `atDamageReceive`（跳过 dying/escaping；易伤 ×1.5、Slow ×(1+0.1n)）；
5. `player.powers` `atDamageFinalGive`；
6. target powers `atDamageFinalReceive`；
7. <0 钳 0 → `multiDamage[i] = MathUtils.floor(tmp)`。
格挡：`applyPowersToBlock()`（L2510-2532）：powers `modifyBlock(tmp, card)` 全员 → `modifyBlockLast(tmp)` 全员 → floor 钳 0。

### (c) `AbstractMonster.calculateDamage(int dmg)`（L1274-1322）— 怪物 intent
DeadlyEnemies → 自身 powers `atDamageGive` → **玩家 powers `atDamageReceive`** → `player.stance.atDamageReceive` → 背击（Surrounded）`(int)(tmp*1.5F)`（中途 int 截断）→ 自身 powers `atDamageFinalGive` → 玩家 powers `atDamageFinalReceive` → floor 钳 0。

**位置要点**：力量（加法）在 give 段；易伤/虚弱/缓慢（乘法）在 receive 段或 give 段（Weak 在怪物 give 段 ×0.75）；Intangible/Flight/Forcefield 在 finalReceive 段。

## 5. AbstractCreature.damage(DamageInfo) 完整流程

### `monsters/AbstractMonster.damage(info)`（L719-827）
1. `info.output>0 && hasPower("IntangiblePlayer")` → `info.output = 1`（**原地修改 DamageInfo**）。
2. `damageAmount = info.output`；isDying/isEscaping 直接 return；<0 钳 0。
3. 记录 hadBlock、weakenedToZero。
4. `decrementBlock(info, damageAmount)`（HP_LOSS 完全无视格挡；THORNS 无视格挡；破格挡时 `brokeBlock()` 触发玩家遗物 onBlockBroken）。
5. 钩子序：`info.owner==player` → 玩家遗物 `onAttackToChangeDamage`；`info.owner!=null` → **攻击方 powers** `onAttackToChangeDamage`；**受击怪物 powers** `onAttackedToChangeDamage`；攻击方遗物 `onAttack`；**受击 powers `wasHPLost`**；攻击方 powers `onAttack`；受击 powers `onAttacked`。
6. `lastDamageTaken = min(damageAmount, currentHealth)`（L798，扣血前记录）。
7. 扣血、`<0` 钳 0；`damageAmount>=99` 触发 overkill。
8. `currentHealth<=0` → `die()`（isDying=true；遍历 powers.onDeath()；玩家遗物 onMonsterDeath；全员死亡时清 limbo/禁用回合按钮）；剩余 block 清空。
- **怪物流程没有 onLoseHp/onLoseHpLast/onInflictDamage**。

### `characters/AbstractPlayer.damage(info)`（L1501-1650）
1. damageAmount = info.output；hadBlock；<0 钳 0；>1 且 IntangiblePlayer → 1。
2. decrementBlock。
3. `info.owner==this` → 自身遗物 onAttackToChangeDamage；`info.owner!=null` → 攻击方 powers onAttackToChangeDamage；自身遗物 + 自身 powers `onAttackedToChangeDamage`（Buffer 在此返回 0）。
4. 自身遗物 onAttack；攻击方 powers onAttack（Envenom 挂毒）；**自身 powers onAttacked**（Thorns/FlameBarrier/StaticDischarge/CurlUp/Malleable/Shifting）；遗物 onAttacked。
5. 遗物 `onLoseHpLast` → `lastDamageTaken = min(damageAmount2, currentHealth)`。
6. `damageAmount2>0`：自身 powers `onLoseHp` → 遗物 `onLoseHp` → 自身 powers `wasHPLost(info, amount2)`（PlatedArmor 掉层、Rupture 加力）→ 遗物 `wasHPLost` → 攻击方 powers `onInflictDamage`（PainfulStabs 塞伤口）。
7. HP_LOSS 计入 hpLossThisCombat；扣血；`updateCardsOnDamage`；isBloodied 判定；`currentHealth<1` 时依次尝试 FairyPotion → LizardTail（counter==-1）→（MarkOfTheBloom 则跳过两者）→ 否则 isDead=true + DeathScreen，并清空格挡。
8. `damageAmount2==0`：显示 "Blocked"。

**两实现钩子顺序不同（移植最大陷阱之一）**：怪物是 `wasHPLost → onAttack → onAttacked`；玩家是 `onAttacked → onLoseHpLast → onLoseHp → wasHPLost → onInflictDamage`。

## 10. 能力列表遍历顺序依赖

- powers 是 ArrayList；所有钩子按列表序遍历。
- 列表顺序 = 插入顺序 + **每次 ApplyPowerAction 新增时按 priority 升序整体重排**。
- addBlock（AbstractCreature:448）顺序：玩家遗物 onPlayerGainedBlock(float) → 玩家 powers onGainedBlock → **所有怪物 powers onPlayerGainedBlock** → `currentBlock += MathUtils.floor(tmp)`（钳 999）。
- MonsterGroup.applyEndOfTurnPowers 顺序：每只存活怪物 applyEndOfTurnTriggers → **玩家 powers atEndOfRound** → 怪物 powers atEndOfRound。
- 回合开始总序（GameActionManager:429-475）：怪物组 applyEndOfTurnPowers → 玩家遗物/卡牌 start-of-turn → applyStartOfTurnPowers → applyStartOfTurnOrbs → 掉格挡 → 抽牌 → applyStartOfTurnPostDrawPowers。
- 玩家结束回合：遗物 → 玩家 atEndOfTurnPreEndTurnCards(true) → powers atEndOfTurn(true) → TriggerEndOfTurnOrbsAction → 手牌 triggerOnEndOfTurnForPlayingCard → stance.onEndOfTurn → 弃牌。

## 11. Rust 移植风险点

1. **amount = -1 哨兵**：stackPower 对 -1 静默忽略 → Rust 建模为 Option/stackable 标志。
2. **float 管线 + 单点取整**：全程 float，末端 MathUtils.floor；个别中途 int 截断（背击、Lockon）→ 逐处复刻。
3. **DamageInfo.output 可变且被受击方改写** → Rust 需 &mut 显式设计。
4. **玩家/怪物 damage() 钩子序不一致** → 拆成两个实现。
5. **priority 排序只发生在 ApplyPowerAction** → 不能每次插入都排序。
6. **死钩子**：onEvokeOrb、onGainCharge 无调用点。
7. **justApplied/skipFirst/triggered 隐式状态机**：8+ 个能力靠布尔标志跳过首次递减。
8. **onRemove 副作用配对**：DrawPower/DrawReductionPower 改 gameHandSize；战斗结束清理不走 RemoveSpecificPowerAction（不触发 onRemove）。
9. **静默全局状态**：TheBombPower.bombIdOffset 静态计数器 → 归入 combat 局部状态。
10. **钩子内修改列表的时序**：stackPower 中 addToTop(RemoveSpecificPowerAction) 不立刻删除 → 复刻动作队列模型。
11. **THORNS/HP_LOSS 特殊旁路**：不进格挡、大多数不进 atDamageGive 修正。
12. **格挡 double/int 双重钩子**：onPlayerGainedBlock(float) floor，(int) 原样——调用点类型决定分派。
13. **球槽位语义**：evoke 顺序"最老先出" + Collections.swap 原地左移；Cables 双触发 0 号球。
14. **updateDescription 副作用**：球的 updateDescription 内部调 applyFocus()（改数值）。
