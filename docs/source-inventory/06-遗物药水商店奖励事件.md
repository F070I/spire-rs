### 1.4 counter 字段语义
- **-1（默认）**：不渲染计数器。
- **-2**：通用"耗尽"哨兵（`setCounter(int)`：`if (setCounter == -2) { usedUp(); counter = -2; }`）。使用者：MawBank、Matryoshka、WingBoots、LizardTail、AncientTeaSet（-2 = 待触发态）、NeowsLament、NlothsMask。
- **≥0 计数器**：VelvetChoker/Kunai/Shuriken/LetterOpener/OrnamentalFan（每回合 0，onVictory 归 -1）；Nunchaku/PenNib（10 攻）；Sundial（3 次洗牌）；IncenseBurner（6 回合）；CaptainsWheel（第 3 回合 18 格挡后 -1）；Girya（持久）；NeowsLament（3 场）；Matryoshka（2 次）；Circlet（重复获得 counter++）；WingBoots（3 次）；TinyChest（4 房一宝箱）。

### 1.5 关键流程方法
- `getPrice()`（L165）：STARTER 300 / COMMON 150 / UNCOMMON 250 / RARE 300 / SHOP 150 / SPECIAL 400 / BOSS 999 / DEPRECATED -1。
- `bossObtainLogic()`（L435）：**HolyWater/BlackBlood/Ring of the Serpent/FrozenCore 四个 Boss 遗物不调 obtain()**（不替换原遗物直接进栏）。

## 2. 遗物如何创建

- **makeCopy 模式**：唯一抽象方法 `public abstract AbstractRelic makeCopy();`，每个遗物 `return new Xxx();`。
- **ID 字符串不统一**：有英文带空格（"Bag of Marbles"、"Black Blood"、"Mark of Pain"）、驼峰（"PureWater"、"FrozenCore"、"MawBank"）、含撇号（"Pandora's Box"）。本地化键即 ID。`hasRelic("字面量")` 遍布代码。
- **RelicLibrary**（helpers/RelicLibrary.java）：5 个静态 HashMap（sharedRelics/red/green/blue/purple），11 个静态 ArrayList（按 tier + 按职业）。`initialize()` 显式 new 全部 177 个。`getRelic(key)` miss 时返回 `new Circlet()`（占位遗物）。`populateRelicPool(pool, tier, chosenClass)`（L423）过滤锁定遗物。

## 3. 遗物池轮换（AbstractDungeon）

- 静态池（L240-245）：commonRelicPool/uncommonRelicPool/rareRelicPool/shopRelicPool/bossRelicPool，元素是 String ID。
- 初始化 `initializeRelicList()`（L1404）：清空五池 → populateRelicPool → `Collections.shuffle(pool, new java.util.Random(relicRng.randomLong()))` → 每日/mod 把特定遗物加入 relicsToRemoveOnStart 并从池删除。存档恢复时 bossRelicPool = saveFile.boss_relics。
- 抽取（L790-929）：
  - `returnRandomRelicKey(tier)`：从池头 `remove(0)`；池空**级联降级**：COMMON→UNCOMMON→RARE→Circlet.ID；SHOP→UNCOMMON；BOSS 空→RedCirclet.ID。取到后 `!canSpawn()` 则**递归重抽**。
  - `returnEndRandomRelicKey(tier)`：从池**尾** remove。
  - `returnRandomScreenlessRelic(tier)`（CallingBell 用）：排除 Bottled 系（无屏幕选不了牌）。
  - `returnRandomNonCampfireRelic(tier)`：排除 PeacePipe/Shovel/Girya。
- **Boss 池消耗顺序**：bossRelicPool 也是 remove(0)；BossChest 构造时一次性 returnRandomRelic(BOSS)×3 消耗前 3 个。
- **tier 掷骰** `returnRandomRelicTier()`（L930）：`relicRng.random(0,99)`，< commonRelicChance → COMMON，< +uncommonRelicChance → UNCOMMON，否则 RARE。

## 4. 药水系统

### 4.1 AbstractPotion（potions/AbstractPotion.java）
- 字段：`ID/name/description; slot=-1; PotionRarity rarity; PotionSize size; PotionColor color; PotionEffect p_effect; potency=0; canUse/isThrown/targetRequired/discarded/isObtained`。
- `PotionRarity { PLACEHOLDER, COMMON, UNCOMMON, RARE }`。
- 抽象方法：`void use(AbstractCreature target)`、`int getPotency(int ascensionLevel)`、`AbstractPotion makeCopy()`。
- `getPotency()` 无参版（L956）：`getPotency(AbstractDungeon.ascensionLevel)`，**持 SacredBark 则 potency ×2**。
- `getPrice()`：COMMON 50 / UNCOMMON 75 / RARE 100 / PLACEHOLDER 999。
- `canUse()` 默认（L396）：WeMeetAgain 事件中禁用；`monsters == null || areMonstersBasicallyDead() || actionManager.turnHasEnded || room.phase != COMBAT` → false。子类覆盖（BloodPotion/FruitJuice/EntropicBrew 只检查 turnHasEnded；SmokeBomb 追加 BackAttack/Boss 禁逃；FairyPotion 直接 false——只能自动复活）。
- `canDiscard()`：仅 WeMeetAgain 中 false。
- `onPlayerDeath()`：默认 false（FairyPotion 走 AbstractPlayer L1616 hasPotion 分支）。

### 4.2 PotionHelper（helpers/PotionHelper.java）
- 静态 `ArrayList<String> potions` = 当前药水池；`POTION_COMMON_CHANCE = 65`，`POTION_UNCOMMON_CHANCE = 25`。
- `getPotions(c, getAll)`（L60）：先加 3 个职业专属（战士 BloodPotion/ElixirPotion/HeartOfIron；猎人 Poison Potion/CunningPotion/GhostInAJar；机器人 FocusPotion/PotionOfCapacity/EssenceOfDarkness；观者 BottledMiracle/StancePotion/Ambrosia），再加 17 普通 + 9 非常见 + 6 稀有（CultistPotion、Fruit Juice、SneckoOil、FairyPotion、SmokeBomb、EntropicBrew）→ 每职业 35 种。**ID 拼写混乱**："Poison Potion"（带空格）vs "CunningPotion"。
- `getPotion(name)`：巨型 switch；未知 ID 返回 `new FirePotion()` 兜底；"Potion Slot" 返回 null。
- `initialize(chosenClass)`：每次进新章重建药水池。
- `getRandomPotion(rng)`：`potions.get(rng.random(size-1))`；无参版用 AbstractDungeon.potionRng。

### 4.3 药水掉落公式
- `AbstractDungeon.returnRandomPotion(boolean limited)`（L941）：`potionRng.random(0,99)`；<65 COMMON、<90 UNCOMMON、否则 RARE；`returnRandomPotion(rarity, limited)` 循环重抽直到匹配。
- **房间掉落** `rooms/AbstractRoom.addPotionToRewards()`（L640-670）：chance = **40 + blizzardPotionMod**（普通战/精英战/事件房同 40% 基础；treasureRoom 不掉药水）；WhiteBeast → 100；`rewards.size() >= 4` → 0；`potionRng.random(0,99) < chance` → 加 RewardItem(POTION)、**blizzardPotionMod -= 10**；否则 **+= 10**。blizzardPotionMod 是 AbstractRoom 静态字段（L79），每章 dungeonTransitionSetup 重置为 0，存档字段 potion_chance。
- **药水槽**（characters/AbstractPlayer.java）：`int potionSlots = 3`（L127）；`ascensionLevel >= 11 → potionSlots--`（=2）；`obtainPotion(potion)`（L2294）：找第一个 PotionSlot 占位 index；`index < potionSlots` → 替换、setAsObtained(index)、**return true**；否则打日志、顶栏红闪、**return false**。PotionBelt.onEquip：potionSlots += 2。FairyPotion 复活：die() 检查 hasPotion 自动使用并 destroyPotion。

### 4.4 药水实现样例（23 个已读）
统一模式：构造器设 rarity/size/color/isThrown/targetRequired → initializeData 拼 potency 描述 → use() 中战斗内走 addToBot(ApplyPowerAction/...)、脱战直接生效（BloodPotion heal、FruitJuice increaseMaxHp(5)）。数值：Fire 20 伤 / Block 12 / Strength 2 / Dex 2 / Swift 抽 3 / Weak 3 / Fear 3 虚弱回合 / Explosive 10 群伤 / Regen 5 / Ancient 1 Artifact / GhostInAJar 1 Intangible / LiquidBronze 3 Thorns / SneckoOil 抽 5+随机手牌费 / Energy 2 / Speed +5 敏后回合 -5 / Cultist 1 Ritual / Fairy 30% 最大 HP / EntropicBrew 每槽一瓶随机药 / SmokeBomb 逃跑（Boss/BackAttack 禁用）/ PotionSlot 空占位（makeCopy 返回 null！）。

### 5.1 常量
`NUM_CARDS_PER_LINE=5`、`CARD_PRICE_JITTER=0.1f`、`RELIC/POTION_PRICE_JITTER=0.05f`、`PURGE_COST_RAMP=25`、`COLORLESS_PRICE_BUMP=1.2f`；`public static int purgeCost = 75, actualPurgeCost = 75`。

### 5.2 init（L121）
1. 卡片由外部传入（Merchant.java 构造生成：`AbstractDungeon.getCardFromPool(rollRarity(), ATTACK/SKILL/POWER, true)` 循环排除 COLORLESS 与重复 ID，5 张职业色卡；第二行 2 张无色卡来自 getColorlessCardFromPool）。
2. `initCards()`（L226）：职业卡价格 `getPrice(rarity) * merchantRng.random(0.9,1.1)`；无色卡再 `*1.2`；每张卡对玩家遗物调 onPreviewObtainCard。**促销**：`merchantRng.random(0,4)` 选一张职业卡 `price /= 2` 并挂 OnSaleTag。
3. `initRelics()`（L359）：3 个 StoreRelic；前 2 个 tier = `rollRelicTier()`（merchantRng.random(99)：<48 COMMON、<82 UNCOMMON、否则 RARE），**第 3 个固定 RelicTier.SHOP**；每个价格 `getPrice() * merchantRng.random(0.95,1.05)`。
4. `initPotions()`：3 个 StorePotion(returnRandomPotion())，价格 ±5%。
5. 折扣叠加（L207-218）：`ascension>=16 → applyDiscount(1.1,false)`（涨价）；Courier → `applyDiscount(0.8,true)`；MembershipCard → `applyDiscount(0.5,true)`；SmilingMask → `actualPurgeCost = 50`。

### 5.3 购买
- **卡** purchaseCard（L620）：金够 → loseGold(price) + FastCardObtainEffect。**无 Courier**：从列表删除。**有 Courier**：原位补货——getCardFromPool(rollRarity(), type, false) 循环排除；无色卡按 colorlessRareChance 掷 RARE；setPrice() 重算。
- **遗物** StoreRelic.purchaseRelic()：金够 → loseGold、relic.instantObtain(player, relics.size(), true)。买 Membership Card 立即 applyDiscount(0.5,true)；买 Smiling Mask → actualPurgeCost=50。**Courier 补货**：returnRandomRelicEnd(rollRelicTier()) 循环排除 **OldCoin/SmilingMask/MawBank/Courier** 后替换自身并重定价；否则 isPurchased=true。
- **药水** StorePotion.purchasePotion()：**Sozu → 直接 flash 并 return**；金不够槽不足（obtainPotion false）→ 商人说话+顶栏红闪不扣金；Courier 补货。
- **移除服务** purchasePurge()（L1037）：金够 → gridSelectScreen.open(masterDeck.getPurgeableCards(), 1, ..., true)（排除瓶装卡）；选中后 updatePurge() → purgeCard()（L260）：loseGold(actualPurgeCost)、**purgeCost += 25**（递增）、重算 actual。
- **Merch idle 台词**：40-60 秒随机说话。
- **抢劫(Mug)机制**：**商店内无 Mug**。抢金是怪物行为（Mugger/Looter → addStolenGoldToRewards → STOLEN_GOLD 奖励）。

## 8. 事件基类结构

文件：`events/AbstractEvent.java`（629 行）、`events/AbstractImageEvent.java`、`events/GenericEventDialog.java`、`events/RoomEventDialog.java`。

### AbstractEvent 字段
`img/roomEventText/imageEventText/drawX,drawY/hideAlpha/hasFocus/body/waitTimer(=1.5,FAST_MODE 0.1)/waitForInput/hasDialog/screenNum/combatTime/noCardsInRewards/optionsSelected`；**static** `EventType type {TEXT,IMAGE,ROOM}`、`NAME/DESCRIPTIONS/OPTIONS`（本地化注入）。

- **`protected abstract void buttonEffect(int paramInt)`** —— 唯一必须实现的钩子，screenNum 状态机内 switch。
- `update()`：waitTimer 倒数到 0 后 show(body)；**每帧检查 `!RoomEventDialog.waitForInput` → `buttonEffect(roomEventText.getSelectedOption())`**（ROOM 型）；IMAGE 型类似。
- `enterCombat() / enterCombatFromImage()`：room.phase = COMBAT; monsters.init(); player.preBattlePrep(); hasFocus=false。
- `openMap()`：phase = COMPLETE; dungeonMapScreen.open(false) —— 事件结束标准出口。
- `showProceedScreen(body)`：单选项 `[ #bProceed ]`，screenNum=99。
- **logMetric 家族**（约 50 个静态重载）：写入 CardCrawlGame.metricData.event_choices。**事件与卡牌操作的实际 API 是直接调 AbstractDungeon/player**：transformCard、masterDeck.removeCard、gridSelectScreen.open、topLevelEffects.add(new ShowCardAndObtainEffect(...))。
- `getSelectedOption()`：waitForInput = true 后返回 selectedOption（-1 初始）——一帧只派发一次。

### 选项与文本显示
- **GenericEventDialog**（IMAGE 事件用）：optionList、selectedOption、waitForInput。`setDialogOption` 9 个重载：`(text)`、`(text, previewCard)`、`(text, previewRelic)`、`(text, card, relic)`、`(text, isDisabled[, ...])`。正文逐词打字机效果；`NL` 换行、`#r/#b/#y` 颜色。
- **RoomEventDialog**（TEXT/ROOM 事件用）：optionList 是 static。
- **LargeDialogOptionButton**：`(slot, msg[, isDisabled][, previewCard][, previewRelic])`。

## 9. Rust 移植风险点

1. **钩子面巨大且无中间层**：AbstractRelic ~55 个虚方法，调用点散布在伤害管线（8 处顺序敏感）、格挡管线、applyPowers（atDamageModify 4 处）、GameActionManager、AbstractDungeon、CampfireUI、AbstractChest.open、PotionPopUp、gainGold/loseGold（Ectoplasm 硬编码在 gainGold 内）→ trait（默认实现）+ 明确派发顺序文档。
2. **静态单例世界**：五个遗物池、六个 RNG、player、currRoom、screen 枚举、RelicLibrary/PotionHelper 静态原型库、RoomEventDialog 静态字段。
3. **ID 字符串是硬契约**：命名混乱（"Bag of Marbles" vs "MawBank" vs "NeowsBlessing"(类名 NeowsLament) vs "Poison Potion"），漏一个 key 会静默落到 Circlet/FirePotion 兜底 → 建 ID→枚举常量表并审计所有字面量。
4. **UI 与逻辑耦合**：ShopScreen 购买直接 loseGold + instantObtain（不进 action 队列）、Bottled* 遗物在 update() 里轮询 gridSelectScreen.selectedCards、CallingBell/PandorasBox 在 update() 里检测"屏幕已关"再发奖励 → 拆成显式阶段/命令。
5. **特殊值与哨兵**：counter=-1/-2、grayscale、usedUp、bossObtainLogic 白名单、Sozu 三处硬编码、WhiteBeast chance=100、rewards.size()>=4 隐藏规则——逐条移植并写测试。
6. **枚举不透明**：PotionColor 22 个值仅调色板（可裁）；RelicTier 的 SPECIAL 与事件奖励绑定（不进随机池）。
7. **makeCopy 的 clone 语义**：遗物有持久状态（counter、Bottled*.card 引用 deck 中的卡）→ Rust Clone/序列化设计中显式处理。
